## 一、配色

### 1.1 强调色推荐：A 鼠尾草绿 `#6B8F71`

四个理由：

1. **护眼文化直连。** 「看绿色护眼」在中文语境里是极强的共识。一个护眼产品用绿色做主色，
   用户不需要被教育就懂它是干嘛的。这是免费的语义。
2. **它是沉静的。** 这个产品的工作是让孩子安静下来专注，界面本身不该是兴奋剂。
   橙色是催促色，绿色是安定色。
3. **和小羊不打架。** 小羊的粉（`#F8B0B8`）留给 EVOLVED 态，蓝留给 SICK 态，
   绿做全局强调，三者色相分得很开，状态一眼可辨。
4. **绿色本来就在角色身上**（三叶草变体），不是外来色。

备选：B 靛青石板 `#4A5D7E`（更严肃、夜间感强，但少了亲和力）。
C 暖褐 `#8B6F5C` 最保守，风险是数据条辨识度不足。

### 1.2 完整色板

| 角色 | 浅色模式 | 深色模式 |
|---|---|---|
| 页面底 | `#F8F8F8` | `#1C1A17` 暖炭（**不用纯黑**） |
| 面板 | `#F0F0E8` | `#26241F` |
| 卡片 | `#F0E8D8` 奶油 | `#302D26` |
| 正文 | `#262421` | `#EDE9E0` |
| 次要文字 | `#8C867C` | `#9A948A` |
| **强调** | **`#6B8F71`** | **`#8FB395`**（提亮以保对比度） |
| 成功 / 达标 | `#6B8F71` | 同上 |
| 注意 | `#C9A227` 芥末黄 | `#D9B845` |
| 异常 / SICK | `#6E86A6` 低饱和蓝 | `#8CA3C2` |
| 腮红 / EVOLVED | `#F8B0B8` | `#F8B0B8` |

**深色模式必须做。** 晚上写作业是主场景，家长也多在晚上看 App。
底色用暖炭而不是纯黑，和奶油底的暖调性格一致。

**强调色占比守住 5% 以内。** 原设计里橙色只占 3.2%，那份克制要继承。

## 二、实时小羊 —— 首页的核心

### 2.1 它解决了一个我之前提出的矛盾

我在功能清单里主张过「不要做实时监视」——因为「孩子刚离开桌子」这种实时推送，
本质是监控，会让孩子对抗设备。

**但把实时状态交给小羊来表达，性质就变了。** 因为：

| 原始表达 | 小羊表达 |
|---|---|
| 「孩子已离开桌子 3 分钟」 | 小羊在打盹 |
| 「距离 28cm，低于安全值」 | 小羊皱眉，凑太近了 |
| 「环境照度不足」 | 小羊眯着眼，光线暗 |

差别有三层：
1. **对象变了。** 看的是宠物的状态，不是孩子的行为记录。
2. **不索取行动。** 小羊打盹不需要家长立刻做什么，「孩子离开了」会。
3. **没有暗中观察。** 孩子在设备上看到的是**同一只羊、同一个状态**。
   家长看到的东西孩子全都知道——这是监控和共享物件的根本区别。

所以我把之前的原则修正为：
**实时可以有，但必须经由小羊表达；实时的原始数值（精确厘米数、在座日志）不进常驻视图。**

### 2.2 技术实现

**不要传设备的画面帧。** 设备没这个带宽，也没必要。

```
设备 ──▶ 后端：{ state, hp, grow, anim, present, 光照/距离标志位 }
App  ◀── 后端：同一份状态
App 本地持有同一套精灵帧，按状态播放对应动画
```

- 更新频率：**10–15 秒轮询足够**。桌宠状态本身变化很慢
  （体力每 30 秒 ±1，动画每分钟一次跳跃）。上 WebSocket 属于过度设计。
- App 端资产：现有 `tooling/asset_builders/` 里 4 个脚本产出的是设备端格式，
  **需要额外导出 Web 友好格式**（雪碧图 / APNG / Lottie）。这是要补的工作量。
- 断连处理：超过 60 秒没有新状态，小羊显示为「休息中」并标注最后同步时间，
  **不要假装它还活着**。

### 2.3 需要补的动画状态

现有：idle、跳跃、低光提醒、休息喝水。建议再补：

| 状态 | 触发 | 表现 |
|---|---|---|
| 打盹 | `AWAY` | 闭眼、轻微起伏 |
| 凑太近 | 距离 < 400mm | 后仰、皱眉 |
| 离线 | 60s 无数据 | 灰度化 + 「休息中」 |
| 被喂食 | 家长操作 | 短促的开心动作 |

## 三、逐页规划

### 1 · 此刻（首页）
- **主视觉：大尺寸实时小羊**，居中，播放当前状态动画。这是 App 的第一印象，给足空间。
- 小羊下方**一句话状态**：「小满在专注学习」／「小羊在打盹」／「光线有点暗，小羊不太舒服」
- Bento 四卡：专注时长 · 护眼分 · 环境 · 提问数
- 今日目标进度环 + 本轮专注计时
- 底部：AI 生成的今日一句话速评

### 2 · 小羊（新增，叙事高点）
- 全屏小羊，**可点击互动**
- HP 条、成长值条、当前形态
- **小羊日记**：用小羊第一人称讲今天发生了什么（AI 生成）
  —— 把冷数据变成情感叙事，这是全 App 最打动人的一屏
- 成长里程碑时间线
- 喂食 / 奖励入口
- 明确标注「孩子在设备上看到的是同一只羊」

### 3 · 护眼
- 今日护眼评分 + **扣分明细**（哪几项各扣多少，可追溯）
- 距离分布：推荐区间 / 过近 / 过远 的时长占比
- 过近事件时间轴
- 近 7 天护眼分趋势

### 4 · 学习
- 今日学习时间轴（在座 / 离开 / 异常 分段条）
- 专注段落：最长连续、平均段长、被打断次数
- 近 7 天专注柱状图（已有，换色即可）
- 一天中效率最高时段（热力条）

### 5 · 环境
- 温湿度当前值 + 舒适区间时长占比
- 光照双路读数 + **左右差值**（判断背光 / 只开台灯没开顶灯）
- 环境异常事件记录

### 6 · 提问
- 对话界面，**小羊做对话头像**
- 预设快捷问题
- 回答内可嵌小图表

### 7 · 提醒与响应（新增）
- 提醒时间轴 + 每条的响应结果
- **提醒响应率趋势** —— 这个 App 最有价值的独有指标

### 8 · 周报
- AI 自然语言总结（Agent Stack 出场）
- 本周 vs 上周对比
- 问题类型 Top 3

### 9 · 设置
- 目标 / 阈值 / 提醒方式（**需配置下行通道**，见架构文档）
- 设备管理、传感器校准
- 孩子档案、多设备

## 四、设计风格推荐

### 推荐：Bento Grid + 柔和编辑排版 + 像素点缀

三层叠加：

1. **Bento Grid 布局。** 大小不等的模块化卡片。当下主流，且**特别适合异构数据仪表盘**
   ——专注时长、护眼分、环境、小羊状态，四类数据形态完全不同，
   等宽栅格会削平它们的层次，Bento 不会。
2. **柔和编辑排版。** 大字号标题（首页「小满今天学得怎么样？」这种问句式很好，保留）、
   充足留白、低饱和。已有设计已经是这个方向。
3. **像素点缀。** 进度条端点、图标、分隔线、里程碑徽章用像素网格语言。
   **关键是让像素成为系统语言，而不是只有小羊一个孤立的像素物件。**

> 这一条是这套设计能否有辨识度的分水岭。目前像素羊是"贴在矢量界面上的吉祥物"，
> 如果把像素网格提炼成 UI 元素，整套设计就有了别人抄不走的签名。
> 分寸是：**像素元素只用在和小羊/成长相关的地方**，数据图表保持干净，
> 否则会变成怀旧游戏 UI，损失专业感。

### 不推荐

- **纸感手账风**：契合学习主题，但纹理容易显旧，且和像素风语言冲突。
- **极简数据仪表盘**：专业但冷淡，会丢掉亲子情感连接，向善叙事直接塌掉。

### 保留原设计的两个决定

- **扁平矢量插画 × 像素羊 的风格对撞**：插画是真实书桌场景，像素羊是住在里面的数字生物。
  这个反差是特色，**不要为了统一把羊改成矢量**。
- **强调色极低占比**：原设计橙色只占 3.2%，靠暖中性色撑场。这份克制继承下来。
